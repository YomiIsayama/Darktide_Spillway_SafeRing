# 泄洪道安全圈高亮（Spillway Safe Ring）
用于显示泄洪道最终首领Boss的地面环攻击的安全区域。

## 效果

- 安全环中心显示紫色 `SAFE / 安全` 世界标记，可在设定距离内穿墙看到。
- 标记中的 `1/4`、`2/4` 等编号表示从内到外的安全圈编号。

## 安装

1. 确保已安装并启用 Darktide Mod Framework（DMF）和 Darktide Mod Loader（DML）。
2. 将 `SpillwaySafeRing` 文件夹放入游戏目录的 `mods` 文件夹。
3. 在 `mods/mod_load_order.txt` 中加入一行：

   ```text
   SpillwaySafeRing
   ```
（使用自动加载autoload则放进mods即可）

## 默认设置

- 总开关：开
- 地面高亮圈：开
- 世界标记：开
- 脉冲闪烁：开
- 地面填充强度：82%
- 标记大小：72
- 标记显示距离：200 米
- 安全圈变化时弹窗：关
